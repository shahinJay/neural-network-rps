# neural-network-rps
A simple neural network I wrote to research about the fundamentals of backpropagation.

## What This Is:
- A complete neural network implementation from first principles
- Manual backpropagation without ML frameworks  
- Training pipeline with data persistence
- Proof that the network learns (errors decrease over time)

## What I've Learned:
- Chain rule derivation for neural networks
- Difference between cost functions and gradients
- Matrix calculus in practice
- Local minima and training dynamics

## Current Challenge: 
Debugging hidden layer weight updates - the final piece of the backpropagation puzzle.

## This Isn't About RPS:
This project is a vehicle for deeply understanding how neural networks actually work at the mathematical level.
